Build and prove your first automation skill

Last session you built a backlog of automation candidates and ranked your top three. Today you take the strongest low-risk one and turn it into a reusable Claude skill — then prove it actually beats doing the work without it.

Thirty minutes, most of it hands-on. Bring your #1 candidate and one scrubbed example of the work.

How the half hour runs

  1. Pick your candidateYour #1 low-risk item from last week's ranked list. Lowest risk, not highest value.
  2. Write the workflow cardTrigger, inputs, output, human review, stop rule, frozen test sample. The card is the contract — nobody builds yet.
  3. Build it, baseline firstCapture what Claude does with no skill, then build the skill and rerun the same sample. Two build paths, same proof required.
  4. Prove it earns its placeA fresh session — or a second model — judges the comparison. Not you, and not the session that built it.
  5. Graduate it, only when provenA scheduled Cloud routine is a graduation, never a first experiment. Optional, and not today's requirement.

Ground rules

Read-only, all session. Nothing gets sent, published, deleted, edited, moved, or re-permissioned in a real work tool.

Scrubbed data only. No patient, customer, financial, or credential data. Use a representative or sanitized example.

A person still makes the final call. We are automating one repeatable piece of work, not a job.

Optional, before we start 5 min

You need one place to build the skill. If neither is set up, come anyway — you can follow along and install afterward, and the workflow card is the part that carries the value.

Skill Factory
The fuller loop — it captures the no-skill baseline for you and holds you to the before/after comparison. If you cloned it back in July, you already have it. Open the folder in Claude Code and say help me build a skill.
git clone https://github.com/augmentgrowth/skill-factory.git
Or install it as a plugin, so it loads in whatever project you're already working in:
claude plugin marketplace add augmentgrowth/skill-factory
claude plugin install skill-factory@skill-factory
Skill Creator
Anthropic's own skill builder. Lighter, and fine for today — it builds the skill and you run the proof step yourself with the prompt in the guide.
claude plugin install skill-creator@claude-plugins-official
Docs: docs.claude.com/en/docs/claude-code/skills

What done looks like

You leave with a workflow card and a frozen scrubbed sample, a no-skill baseline next to a skilled result, a keep / revise / stop verdict from a second opinion, and one named point where a human reviews the output. A scheduled routine is the next step, not today's finish line.
