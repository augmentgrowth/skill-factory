# Skill Factory 0.4.3

- build-skill Step 5 now records its six self-critique checks (Voice, Principles, Anti-Pattern, Example, Model Calibration, Focus) in the new skill's `cases/baseline/self-critique.md` before it dispatches the independent audit. Each check gets a pass or fix verdict, one line of evidence from the draft, and what was fixed. `references/self-critique.md` carries the template.
- The independent auditor's brief now tells it to open that record, confirm all six checks are present, and test each verdict against the draft. A missing file, a missing check, or a verdict the draft contradicts is reported as P2.
- The audit-skill lint reports an L1 `check` when a skill has `cases/baseline/` but no `cases/baseline/self-critique.md`. It is a check, not a fix, so skills built before the record existed are flagged for review, not failed.

## Why

A real build skipped the six checks silently. The progress checklist named them, but nothing recorded that they ran, and the lint and independent audit both passed. Running the checks afterwards found two real failures: no anti-pattern list and no examples. The new build-skill case `cases/2026-10-05-self-critique-unrecorded/` captures that failure.

## Before and after

| Situation | Before | After |
|---|---|---|
| Six checks skipped during a build | Nothing noticed | No record file; the auditor reports P2 |
| Record says "pass" on Example but the draft has none | Not checked | The auditor reports the contradicted verdict as P2 |
| Older skill with `cases/baseline/` and no record | No finding | Lint `check` L1, never a `fix` |
| Skill with no `cases/baseline/` | No finding | No L1 finding (K1 still covers missing cases) |

## Verification

116 unit tests pass, including four new linter tests for L1. The release gate's diagnostic run passes every check. The factory's own skills predate the record, so the lint now reports L1 checks on four of them and no new `fix` findings.
