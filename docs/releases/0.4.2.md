# Skill Factory 0.4.2

- Graduation copies a missing shared, tracked, non-ignored `config.json` on first install. Reinstalls retain existing settings and `.env` files at every depth. The installer excludes repository metadata and rejects overlapping or linked trees before copying.
- The D2 checker recognizes explicit warnings before or after a download-and-execute example. Unrelated warnings no longer hide unsafe instructions, and mixed lines report each command independently.
- Codex discovery notes now include a live 0.154.0 loader verification dated 2026-10-03.

## Before and after

| Example | Before | After |
|---|---|---|
| Fresh install with shared config | Shared config omitted | Shared config included; `.env` omitted |
| Existing personal config | Preserved | Preserved |
| Command followed by “never do this” | Required fix | Warning for judgment review |
| Unrelated warning before unsafe command | Downgraded to review | Required fix |
| Warning example followed by another unsafe command | Second command missed | Both commands reported with their own severity |

## Verification

112 unit tests pass, including eight installer regressions and 54 linter tests. Both Claude plugin validators pass. A fresh independent SOL review verified the scripts and the correction to a cross-command negation bypass found during review. See [Codex discovery receipt](../codex-discovery-2026-10-03.md) for loader scope and limits.

The installer requires Python 3, Git, and rsync. Resolve source links to the canonical skill folder before invoking it; this helper deliberately refuses symlinked trees and does not replace installations managed through links. Existing configuration is never overwritten automatically, so shared-config upgrades still require deliberate reconciliation.
